# 标题与摘要 · content-titles

基于已确认的母稿，生成或优化公众号、抖音的标题、封面文字和摘要。

它是一份用自然语言编写的 Skill，由支持 `SKILL.md` 的 AI 客户端读取和执行。本 Skill 无需另配专用 API 密钥，也不需要爬虫。当前版本：**v1.1.0**。

## 输入和输出

必需输入是已确认的母稿：直接粘贴文字，或提供客户端可读取的明确文件路径。已有候选标题是可选输入，也可以补充目标读者、语气、指定关键词、封面容量和不能改的文字。

默认交付 **1 套推荐结果 + 2 个不同角度的备选主标题**。推荐结果包含以下 8 个字段：

| 平台 | 字段 |
|---|---|
| 公众号 | 主标题、封面副标题、摘要 |
| 抖音 | 发布主标题、封面主标题、封面副标题、摘要、封面关键词 |

封面关键词只给一个，用来概括文章的核心议题。副标题补充主标题的信息，摘要用 1–3 句话交代内容与读者收获。各字段围绕同一个内容核心，不承诺不同的结果。

只需要一个平台或部分字段时，可以直接说明。要求最终版时，省去备选标题。

## 安装

支持 [Skills CLI](https://github.com/vercel-labs/skills) 的环境可运行：

```bash
npx skills add luqi67677/content-titles
```

按提示选择使用的 AI 客户端和安装范围。该命令使用第三方安装工具，需要 Node.js/npm 与网络；Skill 本身是文档，没有额外运行依赖。

也可以下载或克隆 [luqi67677/content-titles](https://github.com/luqi67677/content-titles)，将整个仓库放入所用客户端的 Skill 目录，目录名保持 `content-titles`。保留 `SKILL.md` 与 `references/` 的相对位置，不要只复制单个文件。各客户端的加载方式以其说明为准；`agents/openai.yaml` 是 Codex 的展示与调用配置，其他客户端不必使用。

已经安装的人先确认目标目录，避免覆盖自己的修改。

## 使用

安装后，可以这样提出请求：

```text
用 content-titles，为下面这份已确认母稿生成公众号和抖音的标题、封面文字与摘要。

母稿：
（粘贴母稿）

已有候选标题：（可选）
不能改的文字：（可选）
```

只有主题、还没有母稿时，可以先生成标明“方向草案”的标题方向；正式方案需要母稿提供事实依据。

## 虚构示例

以下母稿与输出均为演示内容。

**母稿**

> 这篇文章给租房者提供三条整理书桌的建议：先只留下当天要用的物品，再按用途把其他物品分盒，最后给盒子贴上标签。读者可以按自己的习惯调整。这些是整理建议，没有实测结果，也没有节省时间的数据。

**一套推荐结果**

公众号：

- 主标题：整理租房书桌，可以先做这3件事
- 封面副标题：从留下什么，到每样东西放哪儿
- 摘要：留下当天要用的物品，按用途分盒，再贴上标签。本文给租房者提供3条书桌整理建议，可以按自己的使用习惯调整。

抖音：

- 发布主标题：租房书桌怎么收纳？先做这3件事
- 封面主标题：先收好一张书桌
- 封面副标题：留当天用品，再分类、贴标签
- 摘要：整理书桌可以从筛选物品、按用途分盒和贴标签开始。这3条建议供租房者参考，具体摆放按自己的习惯调整。
- 封面关键词：收纳

备选主标题：

1. 公众号主标题：整理书桌，先决定今天要用什么
2. 抖音发布主标题：书桌上的零碎物品，可以按用途分盒

示例中的“3件事”来自母稿的三条建议；没有加入“每天省半小时”等母稿未提供的结果。

## 使用边界

- 保留母稿的事实、判断、段落和已锁定文字，不为了标题重写正文。
- 不编造亲历、数字或结果，不把建议写成已经验证的成效。
- 已有标题合适时可以保留；有问题时说明具体原因，给出必要修改。
- 生成的是文案建议，不会自动发布，也不保证流量或预测点击率。

完整流程见 [SKILL.md](SKILL.md)，字段定义见 [references/output-contract.md](references/output-contract.md)。

## 工作区适配

有现成的品牌策略、模板或归档规则时，Skill 会沿用；没有时可以直接提供母稿。可选的本机约定放在 `references/workspace-context.local.md`，该文件被 Git 忽略，不随公开包发布。不要将私有路径、稿件、数据或凭证提交到公开仓库。

## 方法来源

标题结构的早期归纳参考了「数字生命卡兹克」的 233 条微信读书可见标题。公开版只提供抽象方法与自写演示，不分发原始标题集合。副标题、摘要和抖音适配是本项目的设计，尚不能据此宣称有效提升点击率；项目与该公众号无隶属或背书关系。详见 [结构库的来源与边界](references/title-patterns.md)。
