# 字段与输出

默认两平台共 8 项。所有结果来自同一母稿、同一内容核心，禁止不同位置承诺不同结果。

| 平台 | 字段 | 它承担的任务 |
|---|---|---|
| 抖音 | 发布主标题 | 离开封面仍能读懂的内容入口，写清对象与问题、发现或收获 |
| 抖音 | 封面主标题 | 适合视觉扫读的主要一句，突出一个信息 |
| 抖音 | 封面副标题 | 补充对象、证据、适用条件或读者收益，和主标题共同成意 |
| 抖音 | 摘要 | 用 1–3 句交代内容与读者所得，必要时补充条件；不自动变成全文发布正文或添加话题标签 |
| 抖音 | 封面关键词 | 唯一的核心议题词，不是标签列表，不默认拿载体名代替议题 |
| 公众号 | 主标题 | 一句完整内容承诺，可用亲历、问题、选择或判断形成阅读理由 |
| 公众号 | 封面副标题 | 封面上补足主标题的信息，简短且能读懂，与摘要分别交付 |
| 公众号 | 摘要 | 独立概括文章讲什么、带来什么、关键条件是什么；沿用同样的事实和读者价值原则 |

## 默认可复制输出

在两组字段前可写一句推荐理由，文字必须与成品字段分开。每个字段都填完整内容；下方不是需要照抄给用户的占位稿。

**抖音**

- 发布主标题：……
- 封面主标题：……
- 封面副标题：……
- 摘要：……
- 封面关键词：……

**公众号**

- 主标题：……
- 封面副标题：……
- 摘要：……

默认可在成品后给两条不同角度的主标题备选，并标明适合的标题位置。若用户要求多套，把每套写完整；若只要求指定字段，不补整套。

用户已有候选时，可加最多三行有价值的修改对照：原题、建议、原因。已锁定的标题保留原样，其他字段围绕它写；如果锁定标题与母稿矛盾，指出具体问题并将修正版标为建议，不能悄悄替换。

## 交付前逐项核对

- 范围为两平台完整方案时，8 项均存在且没有“同上”或占位符。
- 两个“主标题”字段的职责分清；公众号“封面副标题”和“摘要”各有内容。
- 只有一个抖音封面关键词，概括的是本文核心议题。
- 数量、结果、经历与母稿一致，母稿事实和用户锁定文字未改。
- 主标题有吸引力且承诺有据；副标题和摘要提供补充信息，能独立看懂。

这些检查判断交付是否合格，不生成虚构的点击率、爆款概率或审美精确分。
