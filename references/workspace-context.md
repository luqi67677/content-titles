# 可选工作区约定

本 Skill 默认只需要一份母稿，不依赖特定账号、知识库、数据表、采集工具或 API 密钥。

## 有工作区时

- 遵守当前用户要求与工作区规则，沿用已有的品牌语气、目标读者、封面容量、确认版本及内容项目。
- 用户提供创作策略或模板时按需读取。历史数据按原观察时间理解，不当作实时表现或点击率预测。
- 只读取用户授权、任务相关的资料。母稿足够时直接工作，不为了标题搜集账号配置或额外私人材料。
- 原稿和已确认文字保留。写文件、归档和发布是不同操作，只有用户要求时才做相应动作。
- 缺少可选策略或模板时，说明缺失的影响并继续能完成的工作，不通过未经授权的备份或其他目录绕行。

## 本机补充约定

如果本 Skill 目录内存在 `references/workspace-context.local.md`，在读取策略和生成标题前读取它，用于当前用户的工作区适配；不存在时直接继续，不要求用户创建。

需要长期设置品牌、模板路径或归档方式时，可以把用户确认的约定写在该本机文件中。它已被 `.gitignore` 排除，不属于公开安装包；不要在其中保存凭证。当前用户要求优先于补充约定，补充约定不能扩大读取授权。
